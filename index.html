¿Cómo funciona?
• Al registrarte, tenés 3 días de prueba GRATIS con todo desbloqueado.
• Después, necesitás un token de acceso que podés comprar en Ajustes.
• Cada token te da 30 días adicionales de uso.
• ¡Tus datos NO se pierden! Al expirar el token o la prueba, solo se bloquea la edición. Al ingresar un nuevo token, recuperás el acceso completo.
Manual de Usuario
InicioCargarGestiónVentasConfig
1. Introducción

StreamFlow Pro es tu centro de control para administrar cuentas de streaming.

Al registrarte tenés 3 días de prueba gratis.
2. Cargar Cuentas

Hay tres modos: Cuenta Completa (crea todos los perfiles automáticos), Individual (un solo perfil) y Masiva (pegás un bloque de texto).

3. Gestión de Perfiles

Cada perfil tiene botones: Copiar, Renovar, Libre, Editar, Eliminar, Vender, Reasignar, Duplicar, Pass.

4. Ventas

Al vender un perfil, se genera automáticamente una plantilla para WhatsApp con todos los datos y reglas de uso.

5. Configuración

Podés cambiar tema, modo kiosco, días para "próximo", exportar/importar configuración.

Token de Acceso
💡 Tenés 3 días de prueba gratis. Después ingresá un token para 30 días más. El token se oculta al escribirlo por seguridad.
✅ Tus datos NO se pierden al expirar el token o la prueba.
